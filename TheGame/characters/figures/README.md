# The figures brought in

The only files of the game that are not grown from its own code (intent 0043). Each is a whole person: body,
clothes, eyes, teeth and hair on a skeleton of 84 bones, the face with 65 shapes.

| File | What | From |
| --- | --- | --- |
| `White_M_1_Casual.glb` | VALID's figure `White_M_1`, casual clothes | `avatars/White/White_M_1_Casual.glb` of c-frame/valid-avatars-glb at `c4719df7a2b60a96cc7f56d67e247674b68c4ea7` |
| `White_F_1_Casual.glb` | VALID's figure `White_F_1`, casual clothes | `avatars/White/White_F_1_Casual.glb` of the same |

**VALID**, the Validated Avatar Library for Inclusion and Diversity: Tiffany D. Do, Steve Zelenty, Mar
Gonzalez-Franco and Ryan P. McMahan, "VALID: a perceptually validated Virtual Avatar Library for Inclusion and
Diversity", Frontiers in Virtual Reality 4 (2023), doi 10.3389/frvir.2023.1248915. The library:
https://github.com/xrtlab/Validated-Avatar-Library-for-Inclusion-and-Diversity---VALID (and
https://github.com/google/valid-avatar-library). The files here are its figures as converted to glTF by
https://github.com/c-frame/valid-avatars-glb (Blender, then gltf-transform: meshopt, WebP), taken unchanged; each
recipe keeps its file's SHA-256 (`characters/man.js`, `characters/woman.js`).

Both are under the MIT licence, whose text is in `LICENSE` beside this file and goes wherever these files go.
How a figure stands in the world (its light, its moves, its expressions) is `characters/kit/figure.js`.
