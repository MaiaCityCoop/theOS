# NativeGame

The new game on its own engine, in Rust: a food forest grown from recipes, on land taken from real places. It stands
beside [`TheGame/`](../TheGame/README.md), which keeps running.

Nothing is built here yet. What is wanted, the research behind it and what is decided so far are in intent 0045:
[`Intents/0045-a-food-forest-in-rust.md`](../Intents/0045-a-food-forest-in-rust.md).
