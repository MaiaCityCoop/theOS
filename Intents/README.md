# Intents

Everything made, changed or fixed in TheOS is an intent: one Markdown document here, work package
and changelog in one, moving through **idea → define → build → propose → story → archived**.

- How to work with them: [`.claude/skills/intents/SKILL.md`](../.claude/skills/intents/SKILL.md)
- To open one: copy [`TEMPLATE.md`](TEMPLATE.md)
- To see them as a board, with their stories and the game: `bun run dev` at the repository's root, then http://localhost:5180
